- 根因：案例审核页用 `sessionStorage['rail.audit.latestDraft']` 保存上次会话草稿（documents/chatMessages/auditResult/auditSession 等）；从项目档案“前往审核”只带 `projectId/stageId`（无 sessionId），`created()` 直接 `restoreAuditDraft()` 把上一个案例整体恢复，`loadArchiveSelection()` 仅覆盖项目/阶段名称，不清资料与会话。
- 方案：进入时若带档案绑定（projectId 或 stageId），先比对草稿保存的 `selectedArchiveProjectId/selectedArchiveStageId`：与绑定**同一项目+阶段**才恢复（未完成的同案例可继续）；**不一致则删除草稿**，从空白开始新案例。纯菜单进入（无绑定）仍按原逻辑恢复最近草稿；带 sessionId/workflowId 的恢复路径不变。
- 改动：`RuoYi-Vue-master\ruoyi-ui\src\views\rail\audit\index.vue` `created()` + 新方法 `dropStaleDraftForRouteContext()`（webpack 编译通过）。

### D121 小程序 admin 自动生成任务后白屏/无任务（已修复 2026-09-07）
- 现象：终审自动生成任务后，小程序 admin 打开无任务/白屏，需退出重登才恢复。

- 修复：401 处理同时清 patrol_token/patrol_username 与 `globalData.token/userName` 再跳登录页；首页加载失败不再静默（显示错误文案 + 重新加载按钮，与“暂无任务”区分）。
- 后端核实：当前 admin mini token 可正常列出 9 个任务（含自动生成 RW…008），非后端问题。
